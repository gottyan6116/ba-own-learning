# 分析・施策・マインドマップ拡張 設計

## 目的

プロジェクトに紐づくフレームワーク分析とウェブマーケ分析を基に、保存可能な施策を作成する。マインドマップは文章から生成でき、キーボード主体で編集できるキャンバスへ刷新する。

## 分析と施策

- ヘッダーの表示名を「フレームワーク分析」に変更する。
- ウェブマーケ分析は公開 HTTPS URL 1件と任意メモを入力し、現状、課題、示唆、優先打ち手、KPI、確認事項を生成して履歴保存する。
- `web_marketing_analyses` と `web_marketing_analysis_projects` で分析とプロジェクトを多対多にする。
- プロジェクトの分析タブでは、両種類の分析を集約して「施策を考案」する。
- 施策生成は `project_initiative_batches` に根拠スナップショットを残し、`project_initiatives` に施策を保存する。施策は編集、並べ替え、既存 `project_tasks` への変換を可能にする。

## AI・時間制限

- Workerのページ取得はBrowser Run Freeの60秒上限を明示する。
- Vercel APIはHobbyの最大300秒、Worker呼び出しは295秒とする。
- AI生成は取得後の残時間を使い、構造化JSONをWorkerとNext.jsの双方で検証する。
- 施策とウェブマーケ分析は、既存の共有シークレット付きCloudflare Workerで生成する。公開URL本文・分析本文を信頼できない引用データとして扱う。

## マインドマップ

- React Flowの永続化済みノード・エッジ形式を維持し、ノードdataに見た目・折りたたみ・注記を追加する。
- 中央ルートから左右に枝を伸ばす階層レイアウト、選択時のインライン編集、右クリックメニュー、上部ツールバー、Ctrl/Cmd+Enter・Tab・Enter・Deleteのショートカットを提供する。
- 文章を入力して階層JSONを生成し、既存マップへ置換または追加する。
- ブラウザ内でPNG、SVG、Markdownをエクスポートする。第三者サービスのロゴ・固有資産・画面を複製しない。

## データ保護

- 新規全テーブルにRLSを有効化し、プロジェクトと分析の両方の所有者一致を検証する。
- 過去のフレームワーク分析、マインドマップ、タスクを変更・削除しない。
