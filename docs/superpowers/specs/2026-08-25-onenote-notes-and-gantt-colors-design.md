# OneNote-style Notes and Gantt Colors Design

Notes keeps the approved A layout: an optional organiser, page list, and one writing canvas. It never forces a client, project, or task hierarchy. New pages use one editable surface; the first non-empty line supplies their list title. Existing titles and bodies are retained.

Gantt tasks receive an optional named color: blue, purple, green, orange, red, or pink. When unselected, the current status color remains in effect. The database change is additive and keeps existing task rows valid.
